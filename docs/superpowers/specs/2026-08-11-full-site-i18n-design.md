# TrackFit 全站中英文国际化设计

## 目标

为 TrackFit 增加完整的简体中文和英文界面。所有页面使用带语言前缀的 URL，顶部操作区提供语言切换按钮，首次访问按浏览器语言选择界面，后续记住用户选择。

## 技术方案

- 使用 `@nuxtjs/i18n` 集成 Vue I18n
- 使用 `strategy: 'prefix'`，中文与英文路由分别为 `/zh/**` 和 `/en/**`
- 中文语言代码为 `zh`，语言标签为 `zh-CN`
- 英文语言代码为 `en`，语言标签为 `en-US`
- 翻译文件拆分为 `i18n/locales/zh-CN.ts` 和 `i18n/locales/en-US.ts`
- `/api/**` 继续保持无语言前缀

## 语言选择与路由

- 首次访问无前缀 `/` 时读取浏览器语言列表
- `zh`、`zh-CN`、`zh-TW`、`zh-HK` 等所有 `zh-*` 语言进入 `/zh/`
- 其他语言或无法识别语言时进入 `/en/`
- 用户主动切换后写入 Cookie，后续访问优先使用上次选择
- 切换语言时保持当前页面与查询参数，例如 `/zh/history?type=sleep` 切换为 `/en/history?type=sleep`
- 登录失效时进入当前语言的 `/zh/login` 或 `/en/login`
- 不支持的语言路径不做猜测，按普通未知路由处理

## 导航交互

- 语言切换按钮位于顶部右侧操作区的“退出”和 GitHub 图标之间
- 中文界面显示紧凑的 `EN` 按钮，英文界面显示 `中文` 按钮
- 桌面端与移动端使用相同位置
- 按钮提供本地化的 `aria-label` 和 `title`
- “主页”和“设置”仍保持在主导航中，不插入语言按钮

## 翻译边界

全站翻译以下内容：

- 导航、页面标题、说明、按钮、弹窗、表格和空状态
- 登录、角色、权限、保存、删除、备份与校验提示
- 训练类型、睡眠状态、趋势方向、分析摘要和动态结论
- 内置指标名称、日期展示、HTML `lang`、浏览器标题和页面描述

以下内容不翻译：

- 用户创建的指标名称与单位
- 用户填写的训练备注及其他自由文本
- JSON、接口与日期输入中的原始数据
- `kg`、`cm`、`BMI` 等标准单位

内置指标继续通过稳定的 `code` 识别并按当前语言显示，不修改持久化 JSON。动态分析函数返回稳定的语义结果和参数，由界面层生成本地化句子，不在计算层保存中英文文案。

## 日期与错误处理

- 日期展示使用当前 locale 的格式化能力
- 中文日期示例为 `2026年8月11日 14:30`
- 英文日期示例为 `Aug 11, 2026, 2:30 PM`
- 日期输入、API 时间和 JSON 时间继续使用 ISO 格式
- 服务端错误增加稳定错误码，客户端根据错误码和当前语言显示消息
- 翻译键缺失时回退到英文，开发环境保留缺失键提示

## 测试与验收

- 单元测试覆盖浏览器语言判定、内置指标名称和动态分析语义结果
- 端到端测试覆盖 `/` 的中文与非中文浏览器跳转
- 验证 `/zh/**`、`/en/**` 页面访问和内部链接前缀
- 验证切换按钮在“退出”和 GitHub 之间，桌面与移动端均可操作
- 验证切换语言后保留当前路径、查询参数和登录状态
- 验证刷新后 Cookie 仍保持用户选择
- 验证登录、退出和鉴权跳转保持当前语言
- 验证中英文动态文案、日期及内置指标名称
- 验证用户自定义指标和备注保持原文
- 完成后执行类型检查、Lint、单元测试、构建和 Playwright 端到端测试

## 非目标

- 不增加第三种语言
- 不自动翻译用户输入内容
- 不迁移或升级业务 JSON Schema
- 不改变现有 API 路径
- 不增加在线翻译服务或翻译管理后台
